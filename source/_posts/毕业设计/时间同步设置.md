使用 `timedatectl` 配置时间同步是一种非常便捷的方式来管理系统时间和日期。`timedatectl` 是一个用于管理系统时钟、时区和 NTP（网络时间协议）服务的命令行工具。

下面是如何使用 `timedatectl` 配置时间同步的步骤：

### 1. 检查当前时间和同步状态

首先，你可以使用以下命令来查看当前系统时间和时间同步的状态：

```bash
timedatectl
```

### 2. 启用 NTP 时间同步

要启用 NTP 同步，可以使用以下命令：
```shell
timedatectl set-ntp true

```

### 3. 检查 NTP 状态

启用 NTP 后，可以再次使用 `timedatectl` 命令查看当前状态：

```bash
timedatectl
```
