## 1. 定义gRPC服务 (proto文件)

首先，我们需要定义gRPC服务接口，创建`proto/calculator.proto`文件：

```protobuf
syntax = "proto3";

option java_multiple_files = true;
option java_package = "com.example.demo.grpc";
option java_outer_classname = "CalculatorProto";

package calculator;

// 定义计算器服务
service Calculator {
  // 计算两数之和的方法
  rpc Add (AddRequest) returns (AddResponse) {}
}

// 加法请求消息
message AddRequest {
  int32 a = 1;
  int32 b = 2;
}

// 加法响应消息
message AddResponse {
  int32 result = 1;
}
```

### server.js

```javascript
const grpc = require('@grpc/grpc-js');
const protoLoader = require('@grpc/proto-loader');
const path = require('path');

// 加载proto文件
const PROTO_PATH = path.resolve(__dirname, '../proto/calculator.proto');

const packageDefinition = protoLoader.loadSync(PROTO_PATH, {
  keepCase: true,
  longs: String,
  enums: String,
  defaults: true,
  oneofs: true
});

const calculatorProto = grpc.loadPackageDefinition(packageDefinition).calculator;

// 实现add函数
function add(call, callback) {
  console.log('Node.js服务收到请求:', call.request);
  
  const a = call.request.a;
  const b = call.request.b;
  const result = a + b;
  
  console.log(`计算 ${a} + ${b} = ${result}`);
  
  callback(null, { result: result });
}

// 创建gRPC服务器
function main() {
  const server = new grpc.Server();
  
  server.addService(calculatorProto.Calculator.service, {
    add: add
  });
  
  // 绑定端口并启动服务
  server.bindAsync('0.0.0.0:50051', grpc.ServerCredentials.createInsecure(), (err, port) => {
    if (err) {
      console.error('服务启动失败:', err);
      return;
    }
    
    console.log(`Node.js gRPC服务器运行在端口: ${port}`);
    server.start();
  });
}

main();
```

### GrpcConfig.java

```java
package com.example.demo.config;

import io.grpc.ManagedChannel;
import io.grpc.ManagedChannelBuilder;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

import javax.annotation.PreDestroy;
import java.util.concurrent.TimeUnit;

@Configuration
public class GrpcConfig {

    @Value("${grpc.server.host}")
    private String host;

    @Value("${grpc.server.port}")
    private int port;

    private ManagedChannel channel;

    @Bean
    public ManagedChannel grpcChannel() {
        channel = ManagedChannelBuilder.forAddress(host, port)
                .usePlaintext()
                .build();
        return channel;
    }

    @PreDestroy
    public void closeChannel() {
        if (channel != null && !channel.isShutdown()) {
            try {
                channel.shutdown().awaitTermination(5, TimeUnit.SECONDS);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
    }
}
```

### CalculatorService.java

```java
package com.example.demo.service;

import com.example.demo.grpc.AddRequest;
import com.example.demo.grpc.AddResponse;
import com.example.demo.grpc.CalculatorGrpc;
import io.grpc.ManagedChannel;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

@Service
public class CalculatorService {

    private final CalculatorGrpc.CalculatorBlockingStub calculatorStub;

    @Autowired
    public CalculatorService(ManagedChannel channel) {
        this.calculatorStub = CalculatorGrpc.newBlockingStub(channel);
    }

    public int add(int a, int b) {
        // 构建请求
        AddRequest request = AddRequest.newBuilder()
                .setA(a)
                .setB(b)
                .build();
        
        // 调用gRPC服务
        AddResponse response = calculatorStub.add(request);
        
        // 返回结果
        return response.getResult();
    }
}
```

### CalculatorController.java

```java
package com.example.demo.controller;

import com.example.demo.service.CalculatorService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

import java.util.HashMap;
import java.util.Map;

@RestController
public class CalculatorController {

    private final CalculatorService calculatorService;

    @Autowired
    public CalculatorController(CalculatorService calculatorService) {
        this.calculatorService = calculatorService;
    }

    @GetMapping("/add")
    public Map<String, Object> add(@RequestParam("a") int a, @RequestParam("b") int b) {
        int result = calculatorService.add(a, b);
        
        Map<String, Object> response = new HashMap<>();
        response.put("a", a);
        response.put("b", b);
        response.put("result", result);
        
        return response;
    }
}
```

## 运行说明

### 1. 安装Node.js依赖并启动服务端

```bash
cd node-grpc-server
npm install
npm start
```

### 2. 编译和运行Java客户端

```bash
cd java-grpc-client
mvn clean package
java -jar target/java-grpc-client-0.0.1-SNAPSHOT.jar
```

### 3. 测试

访问 http://localhost:8080/add?a=5&b=3 ，应该返回：

```json
{
  "a": 5,
  "b": 3,
  "result": 8
}
```

## 工作原理

1. Java客户端通过gRPC调用Node.js服务端的add方法
2. Node.js服务端处理请求并返回a+b的结果
3. Java客户端接收结果并通过REST API返回给最终用户

这个demo展示了如何使用Spring Cloud Alibaba生态和gRPC实现Java和Node.js之间的跨语言通信。
