# 二进制更新update

## 语义
表示用户编辑产生相对于state的增量更新statevector
- 向服务端:服务端会持久化，并广播至其他正在编辑的用户，
- 向客户端:表示来自其他正在编辑的用户只要应用更新即可
-
```
// 消息类型定义
{
  "type": "update", // 必填字段，区分数据类型
  "docId": "doc123",                           // 文档唯一标识
  "data": { ... }                              // 二进制的base64格式
}
```

## awareness
表示用户的感知信息
服务端不做处理，只进行广播
```
{
  "type": "awareness", // 必填字段，区分数据类型
  "docId": "doc123",                           // 文档唯一标识
  "data": { ... }                              // 根据类型填充具体内容
}
```

# 重要事项
- data不能嵌套 禁止下面格式
```
{
  "type": "xx", // 必填字段，区分数据类型
  "docId": "doc123",                           // 文档唯一标识
  "data": { 
	"xx"{...}
  }                              // 根据类型填充具体内容
}
```

- 出现非正常情况以下字段不为空会返回:
### exceptionCode
- 正常情况是null
- exceptionCode=10 :表示文档目前state是空的
-  exceptionCode=1 其他错误情况
### msg
正常情况为空，异常情况会包含提示信息
