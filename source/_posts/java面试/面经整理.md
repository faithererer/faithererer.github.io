cookie 和 session的区别

- **存储位置**：Cookie 存储在客户端，Session 存储在服务器端。
- **生命周期**：Cookie 可以设置为长期有效，Session 一般在用户不活动一段时间后自动失效。
- **安全性**：Session 相对更安全，因为数据保存在服务器端。
- **适用场景**：Cookie 适用于保存一些非敏感的、需要长期保存的信息，比如用户偏好设置。Session 适用于保存敏感的、短期内有效的信息，比如用户登录状态、购物车信息等。

注意：自动转换按从**低到高**的顺序转换。不同类型数据间的优先关系如下：

    低--------------------------------------------->高

    byte,short,char-> int -> long -> float -> double

  
byte,short,char是同级别的，不能自动转换，需要加强转,Java中涉及byte、short和char类型的算术运算首先会把这些值转换为int类型，然后对int类型值进行运算，最后得到int类型的结果。
